# 文書の索引

アプリ本体の計画書・調査メモの一覧。番号は作った順で、ファイル名は
`<番号>-<名前>.md`。見出しは各文書の 1 行目 (h1) から取っている。

## 番号の約束

- 新しい文書は最大番号 + 1 で作り、この索引に 1 行足す。
  番号が重なっていた 47・48 の後発は 94・95 に振り直した
  ([93-リファクタリング計画.md](93-リファクタリング計画.md) §2-6)
- **01〜21 番はこのリポジトリに無い。** ワークスペース側 (このリポジトリを
  置いている非公開リポジトリ `41-QR-search`) の `docs/` にある移行計画・
  調査メモで、04 番以降はアプリ側と番号が重なる。コメントや文書から指す
  ときは `41-QR-search/docs/12-添付ファイル種類拡張メモ.md` や
  `41-QR-search/docs/14 §Phase3` のように接頭辞を付ける。
  接頭辞の無い `docs/12` はアプリ側 (ここ) の文書を指す
- `05-全文検索の使い方.md` と `メモ記法.md` はアプリのヘルプ画面
  (`/docs/search`・`/docs/memo`) がそのまま読み込む。改名するとヘルプが壊れる

## 参照の検査

```bash
node scripts/checkDocLinks.mjs
node scripts/checkDocLinks.mjs --workspace-docs=../docs
```

README・`docs/`・`src/`・`scripts/`・直下の `*.sh`・`deploy/`・`Dockerfile`・
`compose*.yaml`・`next.config.ts` の中の `docs/<番号>-<名前>.md`・番号だけの
`docs/<番号>`・markdown の `.md` リンクを拾い、指す先が無ければ一覧を出して
終了コード 1 で終わる。`41-QR-search/docs/` 付きの参照は `../docs` が在るとき
(またはディレクトリを明示したとき) だけ検査し、公開リポジトリを単独で
clone した環境では飛ばす。ファイルを動かしたり文書を振り直したりしたら流す。

## 環境変数と上限の検査

```bash
node scripts/checkEnv.mjs
```

`.env.example`・`compose.yaml` の app の `environment:`・コードの `process.env` の
食い違い (「`.env` に足したのにコンテナに届かない」など) と、`Caddyfile`・
`deploy/nginx/*.conf`・`src` の定数に書かれた本体サイズ上限の大小関係
(エッジ ≥ アプリの門、など) を見る。想定外のずれがあれば終了コード 1
([93-リファクタリング計画.md](93-リファクタリング計画.md) §7-3)。
