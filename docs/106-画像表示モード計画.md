# 画像表示モード計画

ノート本文の画像を、PDF ビュアーのように「全体を表示」と「幅に合わせる」で
切り替えられるようにする。既定は全体を表示。想定はイラストだが、画像の種類は
限定しない。

## 1. 2 値で足りる

- **全体 (page)** … 画像の高さを「ノートが見えている高さ」までに抑える。幅は
  もとから器の幅まで (prose の `max-width:100%`) なので、両方に収まる。
- **幅 (width)** … 高さの上限を外す。これまでの見た目。

横長の画像は幅で先に詰まるので、どちらのモードでも同じ見た目になる。変わるのは
縦長の画像だけ。PDF ビュアーにある「実寸」や拡大率は持たない。原寸で見る役目は
拡大表示 (ZoomableImage の覆い) が既に持っていて、覆いは常に全体を表示する。

## 2. 高さの基準は画面ではなくノートの器

`100dvh` を直に使わない。3 ペインのノートは 45dvh のペインの中にあり、
画面の高さで抑えてもペインからはみ出して「全体」にならない。

ノートの見える高さを CSS 変数 `--note-view-h` 1 つで持つ。

| 器 | 値 | 置き場 |
| --- | --- | --- |
| 単独ページ | `100dvh - --header-h - --bottom-bar-h` | globals.css |
| ペイン | `--preview-pane-h` | PreviewPane |
| 全画面のペイン | `100dvh - --header-h` | PreviewPane |

画像の上限はここから `--note-img-reserve` (4rem) を引いた値。ペイン上端に
貼り付く操作行と画像の上下の余白のぶんで、引かないと下端が少し隠れる。

container query (`container-type: size` + `cqh`) は採らなかった。器に size の
封じ込めが掛かり、器の中の fixed / sticky の振る舞いが変わる危険のほうが
大きい。器の高さはどれも CSS 変数で決まっているので、同じ式を写せば足りる。

## 3. 縮める対象

`[data-note-body] img[data-zoomable]:not([width])` だけ。

- `data-note-body` は NoteBody が本文の器に付ける。一覧のカードのプレビュー
  (NotePreviewThumb) と記法ヘルプ (docs/memo) は NoteBody を通らないので縮まない。
- `data-zoomable` は ZoomableImage の本文側の img に付ける。回路図などの図は
  対象外。
- 幅記法 (`![|200]`、docs/73) の付いた画像は除く。書き手が決めた大きさは
  読み手のモードより優先する。
- 印刷では効かせない (`@media screen`)。

## 4. 設定は端末単位、正本は localStorage

ページ送り (docs/82 §3、prefs/notePager.ts) と同じ判断と同じ形。幅で見たい人は
どのノートでも幅で見たいはずで、ノートごとに覚えると開くたびに見た目が変わる。

- key は `qr-search:image-fit`、値は `page` / `width`。知らない値は既定に倒す。
- サーバ描画は既定 (page) で描く。幅を選んだ端末だけ、hydration の後に一度
  切り替わる (通し表示と同じ挙動)。
- 印は ImageFitScope (client) が `data-img-fit` として本文の器の外側に立てる。
  CSS の既定が全体なので、`[data-img-fit="width"]` の器だけ上限を外す。

## 5. 切替ボタン

見出し行のページ送りの右に置く (ImageFitToggle)。作りはページ送りの切り替えに
揃え、文字を持たず、いまの状態のアイコンを出し、名前と説明は aria-label と
長押しの吹き出しが言う。色は amber で、見出し行の他の操作と重ならない。

- 全体を表示中: 枠の中に縦長の絵が上下とも収まった形。
- 幅に合わせ中: 枠の左右いっぱいの絵が下へはみ出す形。

自前の画像 (`allImageNames`) の無いノートには出さない。押しても見た目が変わらない
ボタンになるため。外部 URL の画像だけのノートはボタンが出ないが、既定の全体表示は
効く。

## 6. 公開ビューとオフライン表示

ImageFitScope で包まないので、ボタン無しで既定の全体表示に固定される。

## 7. 確認したこと

ローカルの dev サーバで、幅 414px・高さ 800px で測った。

| 場面 | 縦長 800×2000 | 横長 1600×600 | 幅記法 200 |
| --- | --- | --- | --- |
| 単独ページ・全体 | 275×688 | 341×128 | 200×500 |
| 単独ページ・幅 | 341×853 | 341×128 | 200×500 |
| 2 ペイン (360px)・全体 | 118×296 | 341×128 | 200×500 |

iPhone 実機は未確認。
