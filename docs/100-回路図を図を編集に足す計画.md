# 回路図 (circuit) を「図を編集」に足す計画

計画日: 2026-09-23 / 状態: **計画**

[99](99-フェンスGUI編集計画.md) の Phase 3。「図を編集」(下部バー) で開ける
フェンスに、回路図の YAML フェンス (` ```circuit `。[91](91-回路YAMLフェンス計画.md))
を足す。板の 2 つ (breadboard / perfboard) で殻の配線は済んでいるので、
**足すのは言語 1 つと処理系の読み込みだけ**。

99 が circuit を後回しにした理由は「circuit-fence/core をブラウザに載せるのは初めてで、
大きさを測ってから」だった。測った (§1)。

## 1. 手元で確かめたこと (2026-09-23)

いま vendor にある circuit-fence **0.8.0** の core を node で直に呼んだ。

| 何 | 結果 |
| --- | --- |
| `createCircuitEditor()` | 0.8.0 に**もう入っている** (`circuit-fence/core` の出口)。版を上げなくてよい |
| `view()` (掴む用の図) | 抵抗 1 つ・コンデンサ 1 つ・配線 1 本で **7.4 ms、6.5 KB**。`<svg>` に `.cf-cell[data-address]` と `.cf-chip[data-part]` が付く。**TeX は要らない** (上流は清書の SVG から位置を読めないので、つながりだけの図を別に描く。52 の docs/08) |
| `movePart(src, 'R1', 'b3')` | 通る。2 か所の桁の書き換え (`a1`→`b3`、`a2`→`b4`) が返る |
| `fine` | 10 (1/10 升まで刻める。板の 2 つとは違う) |
| `problems` | **無い** (帯の「検査 N」は出ない。0.9.0 で入った口で、無くても殻は動く) |
| `FenceEditor` の型 | fence-kit 0.1.0 の型との違いは、省略できる `problems` だけ。**構造で合う** |
| core の大きさ | 185 KB / **gzip 60 KB** (breadboard は 166 KB / 55 KB)。外の依存は `yaml` だけ |
| `LookSource` (引数) | 注釈に枠を付けるか、の 1 項目。既定 (付けない) でよいので渡さない |

## 2. 決め

| # | 決め | なぜ |
| --- | --- | --- |
| 1 | **対象に `circuit` を足す。** `circuitikz` (素の TeX) は足さない | 上流に editor があるのは YAML の側だけ。TeX の図は位置が読めない |
| 2 | **版は上げない** (circuit-fence 0.8.0 のまま) | 0.8.0 に editor が入っている (§1)。上げるとキャッシュの鍵が変わり、配布後に `./doBackfill.sh circuits` が要る (91 §3)。0.9.0 で得られるもの (USB コネクタ・帯の検査) はこの計画と関係ないので、別の機会に backfill とセットで |
| 3 | **処理系はノートに書いてある言語の分だけ読む。** 開くとき本文を走査して (`guiFenceLangsIn`)、その言語の core だけを動的 import する | 3 つ全部だと初回に gzip 170 KB。板 1 種類のノートなら 55 KB で済む。殻の一覧 (picker) には読んだ言語のフェンスだけが出るが、混ざったノートは両方読むので欠けない。走査の規則は `fenceAtCursor` と同じ (開きの行を上流の規則で見る) |
| 4 | 編集するのは**掴む用の簡略図** (上流の作り)。清書の回路図は閉じた後、いままでどおりサーバの TeX で描き直す | 上流がそう作ってある (52 の docs/08「掴むための似顔絵」)。清書の上で掴む仕組みは上流に無く、ここで作るものでもない |
| 5 | 閉じた後の描き直しは**今までの経路のまま** (ライブプレビュー → `/api/circuits` → TeX → `circuit_svgs`)。何も足さない | 閉じる = 本文の 1 回の書き換えで、打鍵で書き換えたのと同じ。1 回につき TeX 1 回・控え 1 行で、今までと変わらない |
| 6 | 書式メニューの雛形は足さない | 「回路図 (YAML)」が既にあり、入れた直後にカーソルが中に落ちる |
| 7 | `createCircuitEditor()` に引数は渡さない | §1 のとおり既定でよい。QR ノートに設定の口も無い |

## 5. 確かめること (実機)

| 何 | 期待 |
| --- | --- |
| iPhone で circuit フェンスから開く | 簡略図が出て、部品を掴んで動かせる。1/10 升の刻み (Ctrl) は指では効かないが、置くだけなら要らない |
| 閉じた後 | 数秒で清書の回路図に差し替わる (TeX)。その間は今までどおり「描画中」 |
| 板と回路図が混ざったノート | 殻の一覧に両方のフェンスが並び、選び直せる |

## 6. やらないこと

- **circuitikz フェンス** (決め 1)
- **circuit-fence の版上げ** (決め 2)。0.9.0 の帯の検査 (`problems`) が欲しくなったら、
  backfill とセットの別の計画で
- **清書の回路図の上で掴む** (決め 4)
- **閉じた後の描き直しを速くする**。回路図の描画は 91 の作りのまま
