# 全幅レイアウト計画 (本文の器と下部バーを画面いっぱいに)

計画日: 2026-09-23 / 状態: **実装済み**

## 1. 何が困っていたか

PC のブラウザでノートを開くと、本文・タブ・下部の編集バーが画面の中央
672px (`max-w-2xl`) に収まり、左右が大きく空いていた。編集バーは 672px に
18 個のボタンが入らず、広い画面なのに横スクロールしないと奥のボタンに
届かなかった。

ユーザーの指定: **下部のメニューも、タブを含むページ全体も、ブラウザの
幅いっぱいに広げる。**

## 2. 決め — 読み幅の上限をやめる

672px の上限は「メモの本文が読める行長に収める」ための意図的な設計だった
([31](31-下部操作バー計画.md) §12-4、[86](86-検索3ペイン計画.md) §4-8)。
この計画はそれを**改める**。

- 3 ペイン・2 ペインでは既に全幅だった (globals.css が `max-width:none`)。
  今回は 1 ペインと単独ページ (`/item`・`/edit`・`/new`・ゴミ箱など) を
  それに揃える形になる
- スマホ縦持ちは画面が 672px より狭いので見た目は変わらない。横持ちの
  896px 緩和 (`landscape-phone:max-w-4xl`) も要らなくなった
- 懸念: 1920px の画面では markdown の本文が 1 行 200 字を超える。
  読みづらければ「markdown タブの本文だけ幅を絞る」を後から足す

## 3. 作り

### 3-1. 幅の上限は 1 か所で持つ

`src/components/ui.ts` の `CONTENT_WIDTH_CLASS` に集めた。値はいまは
`max-w-none` (上限なし)。使う側は次の 4 つで、どれも `mx-auto` を残して
あるので、上限を戻したくなったらこの定数を書き換えるだけで中央寄せに戻る。

| 場所 | 何の幅か |
| --- | --- |
| `app/layout.tsx` の `<main>` | 全ページの本文の器 |
| `ui.ts` の `BOTTOM_BAR_INNER_CLASS` | 下部バーの中身 (編集ボタンの帯) |
| `panes/PreviewPane.tsx` | ペインで開いたノートの操作行と本文 |
| `chrome/DemoBanner.tsx` | デモ環境のバナー |

globals.css のペイン用の `max-width:none` と `margin-inline:0` は**残す**。
上限を戻した日にも、3 / 2 ペインの一覧 (`main`) だけはペイン幅いっぱいに
保つためのもの。

### 3-2. 編集バーのボタンは収まれば均等に並べる

器を広げるだけだと、ボタンは自然幅のまま左に寄り、右が空く。横スクロール
の帯 (`EditToolbar`) に `justify-between` を付けた。

- 収まるとき … 帯の幅いっぱいに均等に並ぶ
- 溢れるとき … `space-between` は負の余白で `flex-start` に落ちるので、
  従来どおり左端から横スクロールになる
- `space-around` / `space-evenly` は使わない。溢れたときの落ち先が
  中央寄せになり、左端のボタンに届かなくなる (§12-3 の
  「justify-center + overflow」と同じ罠)

### 3-3. 役目を終えたものを外す

- `WIDE_RESULTS_CLASS` (カード表示だけ器からはみ出させる細工) と、その
  判定 `usesWideResults` を削除。器が全幅になると、上限 1152px のこの細工は
  逆に器より狭くなる。残っていた使用先はゴミ箱だけだった
- `PreviewPane` の `PANE_WIDTH_CLASS` を削除。ペインと全画面で幅を分ける
  理由が無くなった
- `SearchResults` の `className` 引数を削除。唯一の用途が広幅の細工で、
  既に誰も渡していなかった

### 3-4. 据え置いたもの

別の判断なので今回は触らない。

- ハンバーガーの下からのシート (`HeaderMenu`)。ページではなく一時的な
  ポップアップで、全幅にすると PC で画面を横切る帯になる
- ゴミ箱の下部バー (`BOTTOM_BAR_INNER_NARROW_CLASS`)。2 スロットを
  320px に絞るのは押す的の大きさの判断 ([67](67-ゴミ箱表示形式計画.md) §4)
- シークレットのダイアログ
