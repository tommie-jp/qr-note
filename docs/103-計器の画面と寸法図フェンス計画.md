## 3. `data:` をどう読むか

上流は `options.data: (name: string) => string | null` を受ける。**名前から本文の文字列を返す
同期の関数**で、ファイルを読むのは呼ぶ側の仕事。VS Code では `.md` の隣のファイル、
playground では頁の「添付」を渡している。

QR Note の添付は、保存名が `UUID.拡張子` で元の名前を持たない。一方、本文には
`![3-1.csv](UUID.csv)` のように、**画像の記法の alt に元の名前が残る**。

| # | 決め | 理由 |
| --- | --- | --- |
| 1 | **`data: 名前` の名前は、同じメモの添付の alt (`![名前](…)`) で引く** | 本文だけで決まる。メモの外のファイルを引かない。名前の食い違いはお知らせに出せる |
| 2 | 描く前に、本文の `data:` が指す名前を拾い、添付を**先に取りに行く** (`/api/images/…`)。取れたら同期の `data` 関数に Map で渡す | core の関数が同期なので、非同期の取得は呼ぶ側で済ませる |
| 3 | 取りに行くのは**そのメモの本文に出てくる添付だけ**。上限を置く (1 図 1 MB・1 メモ 8 ファイルなど。数は実測で決める) | 他人の書いたノートを描く前提 (circuit-fence の方針と同じ) |
| 4 | 名前が引けなければ、上流の既定の挙動 (理想の線だけを描く) に任せ、お知らせに「添付が見つからない」を足す | 図は消さない (97 の決め 7) |
| 5 | **添付の形式に `s1p` `s2p` を足す** (`textFormats.ts` の `defineFormats`) | Touchstone を貼れない。足す場所は 5 か所あると書いてあるので、足し忘れの検査 (`defineFormats.test.ts`) に載せる |

`.s2p` を許すのは安全面でも問題ない。テキストは `text/plain` + `nosniff` で配る作りで、
拡張子を限っているため (`textFormats.ts` の冒頭のコメント)。

## 9. 第 1 段の実装の結果 (2026-10-13)

(このあと main に merge し、v0.23.20 で本番へ配布した。下の「できていないこと」は
2026-10-18 の時点でも、コードで確かめられる範囲では変わっていない —
ライブプレビューは今も `data:` を渡さず (`fenceBlocks.ts`)、e2e も無い)

- 6 つの tgz (copper 0.10.0・vna 0.8.0・scope 0.7.0・spectrum 0.4.0・graph 0.3.0・logic 0.2.0)
  を `vendor/` に置いた (SHA256SUMS 照合済み)。6 つの言語を `BOARD_LANGS` に足したので、
  閲覧 (`MarkdownView`)・編集のライブプレビュー (`fenceBlocks`) は既存の経路に載った
- `data:` は `dataAttachments.ts` (名前の拾い出し・添付の索引・取得) と `BoardDiagram.tsx`。
  取れなかった理由は図の下のお知らせに出し、図は理想の線だけで出る
- 添付の形式に `s1p` `s2p` を足した (`textFormats.ts`・`names.ts`・ファイル選択・文言)
- **確かめたこと**
  - 上流の例 74 件と、**教科書の 6 種のフェンス 765 件**を `renderBoardFence` で描いた。
    例外 0・読めない行 0 (SVG の許可リストも全部通る)
  - `npm run typecheck`・`npm run lint`・単体テスト 4624 件が通った。`next build` は
    **コンパイルまで通り**、その先はこの環境に `DATABASE_URL` が無いため止まった
    (配布スクリプトが与える。既存の警告 `notesRepo.ts` は今回と無関係)
- **見つけて直したこと**: 打ち間違いの警告 (`suggestFenceLang`) が、短い新語を理由に
  普通の言語を巻き込んだ (`ini` `lua` `vba` `vue` → `vna`、`graphql` `grep` → `graph`、
  `log` → `logic`)。近いと見る距離を**言語の長さで決める**ようにした
  (3 文字以下は大文字小文字だけ、5 文字以下は 1 文字違いまで)
- **できていないこと**
  - **ライブプレビュー (編集画面) は `data:` を読まない** — 閲覧では重なる
  - **実際の添付を貼ったメモでの画面確認は、していない** (単体テストと描画だけ)
  - e2e (Playwright) は回していない
  - gzip 後の大きさと描画時間は測っていない
- 外部画像 (`https://…svg`) の表示: コードに CSP や外部画像を断る箇所は見つからず、
  react-markdown の `urlTransform` と sanitize は `http(s)` の `src` を通す。**ブラウザでの
  表示は確かめていない** (104 の §6 は未確認のまま)
