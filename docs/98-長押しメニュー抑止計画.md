# 長押しメニュー抑止計画 (iOS のコピー・共有の吹き出し)

実装日: 2026-09-23 / 状態: **実装済み** (iPhone 実機は未確認)

## 1. 何が困っていたか

iOS は長押しで文字を選んで「コピー / 調べる」を出し、リンクや画像には
プレビューや「共有」の吹き出しを出す。アプリ自身の長押し (メニュー・
PressTip) と重なるうえ、ボタンを押し損ねただけでも出て煩わしい。

目立っていたのは**検索窓の下の見出し行** (表示・並び順・選択)。
[86-検索3ペイン計画.md](86-検索3ペイン計画.md) §4-11 で下部バーから
見出し行へ移したとき、長押しメニューは付いてきたのに、バー
(`BOTTOM_BAR_CLASS`) が持っていた `select-none` と
`-webkit-touch-callout: none` が付いてこなかった。ほかの画面でも出ていた。

## 2. 決め — 画面全体で止めて、要る所だけ戻す

**部品ごとに止める形をやめる。** 止める指定を部品に持たせると、部品を
別の場所へ移したときに抜ける (§1 がその実例)。向きを逆にして、既定を
「出さない」にする。

出してよい場所はユーザーの指定で決めた — **ノートのタブ (markdown /
テキスト / 編集) の中だけ**。読む・書く場所で、文字の選択も画像の共有も要る。

| 場所 | 長押しの OS メニュー |
| --- | --- |
| 検索画面・一覧・見出し行・ヘッダ・下部バー・設定など | **出さない** |
| ノートのタブ (markdown / テキスト / 編集) の中 | 出す (文字選択・リンク・画像の共有と保存) |
| 文字を打つ欄 (検索窓・タイトル・タグなど) | 出す (ペースト) |
| `/edit` の本文 (CodeMirror) | 出す (contenteditable) |

- **欄はどこでも戻す。** 選べないと長押しのペーストもカーソル移動のルーペも
  出ず、入力が成り立たない。iOS は `-webkit-user-select: none` の下で欄に
  打てなくなることもある
- **指の画面 (`hover: none`) だけ。** PC のマウスは長押しに化けないので、
  一覧のタイトルを選んでコピーする手を残す
  ([66-行アクション計画.md](66-行アクション計画.md) §5-2 と同じ判断)

## 3. 作り

- `globals.css` の `@media (hover: none)` — `body` に
  `-webkit-user-select` / `user-select: none` と `-webkit-touch-callout: none`。
  `[data-os-menu]` と欄 (`input` / `textarea` / `contenteditable`) で
  `text` / `default` に戻す
- `MemoPanel` がタブの中身の枠に `data-os-menu` を付ける。タブの見出し
  (tablist) は押す物なので外に置いたまま
- `-webkit-touch-callout` は継承する。`user-select` は継承しないが、子が
  `auto` の間は親の `none` / `text` が使われる。子で明示した指定はそのまま勝つ

## 4. 意図して残したもの

- **PDF ビューアの文字層** (`.textLayer` の `user-select: text`)。文字を選ぶ
  ための層で、明示指定が body に勝つ。モーダルは body へ portal されるので
  タブの外だが、選べるまま
- **復旧キーの `select-all`** (設定の鍵束)。控えを写すための表示
- **拡大表示の画像は共有メニューが出ない。** `ZoomableImage` の拡大は
  `ModalOverlay` で body へ portal されるのでタブの外。本文の中の画像
  (拡大前) では出る
- 部品ごとの指定 (`BOTTOM_BAR_CLASS` / `PressTip` / `SwipeToTrashRow`) は
  消していない。スマホでは重複だが、バーと PressTip の `select-none` は PC にも
  効いている

## 5. 確認

- 単体: `MemoPanel` の印がタブの中身の枠にだけ付く
- E2E (`e2e/touch-callout.spec.ts`。Chromium の hasTouch): 見出し行の「選択」の
  文字が選べない / 検索窓は `text` / 3 つのタブの中は選べる / タブの見出しは
  選べない / PC では選べる。印を外すとタブのテストが落ちることも確かめた
- `-webkit-touch-callout` は Chromium も Linux の WebKit も解さないので、
  吹き出しは iPhone 実機で見る:
  1. 見出し行の表示・並び順を長押し → アプリのメニューだけが出る
  2. 一覧の行・ヘッダ・下部バーを長押し → OS の吹き出しが出ない
     (行メニューは従来どおり)
  3. markdown タブの本文を長押し → 文字選択とコピー。画像の長押し → 共有・
     "写真"に保存
  4. 編集タブ・`/edit`・検索窓を長押し → ペースト
