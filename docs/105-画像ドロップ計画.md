# 画像ドロップ計画

計画日: 2026-10-17 / 状態: **実装済 (ブランチ feat/drop-anywhere)**

ノートの編集画面で、Windows のエクスプローラやブラウザの別タブから画像を
ドロップして添付できるようにする。貼り付け (Ctrl+V) と同じ流れに乗せる。

## 1. 結論

- **本文の上へのドロップは前から動いていた。** `useAttachmentInsert` の
  CodeMirror の口が受け、貼り付けと同じ `insertFiles` でアップロードする
- 足りなかったのは次の 2 つ。どちらも足した
  - **本文の外に落とすと、ブラウザがファイルをタブで開く。** 編集画面が消えて
    「ドロップが効かない」に見えていた。編集画面全体を受け皿にした (§2)
  - **別タブの画像を引っ張ると、URL が素の文字で入る。** ファイルは来ない。
    画像の URL なら画像記法で入れるようにした (§3)
- ドロップは原本を指すので、上限を超えても縮めない
  (docs/92-クリップボード連携計画.md §4 の方針のまま)

## 2. 編集画面全体を受け皿にする

- `hooks/useDropZone.ts` が `MemoEditorInner` の最上位の div に
  dragenter / dragover / dragleave / drop を付ける。React のイベントは portal を
  抜けて親に伝わるので、下部バーのツールバーに落としても受かる
- 受けるのは `dataTransfer.types` に `Files` か `text/uri-list` があるときだけ。
  文字のドラッグ (本文内の移動) は CodeMirror に任せる
- 本文の上のドロップは CodeMirror の口が先に処理して preventDefault する。
  受け皿は `defaultPrevented` を見て何もしない (二重に入れない)
- 本文の外では座標から位置が引けないので、今のカーソルの位置に入れる
- ドラッグ中は本文の枠を青で縁取り、文字数の行に「離すと挿入します」を出す。
  dragenter / dragleave は子要素を跨ぐたびに対で出るので、数えて 0 で消す
- 受け皿で受けたものは、入れられなくても preventDefault する。任せるとページを
  離れる (ファイルを開く・リンクへ移る)
- 編集画面の外 (ヘッダなど) に落とした場合は対象外。離脱は beforeunload の
  確認 (UnsavedGuard) が止める

## 3. URL のドロップ

判定は `lib/editor/dropFiles.ts` の `droppedImageUrl`。

- `text/uri-list` を持ち、`text/html` が**文字を含まない** `<img src>` だけなら、
  その src を採る。拡張子の無い CDN の画像も拾える。文字を含む HTML から採ると、
  画像入りの段落を引いたときに文章が画像 1 枚に化ける
- 無ければ `text/uri-list` の最初の URL を、画像の拡張子
  (png / jpg / gif / webp / avif / svg / bmp) を持つときだけ採る
- http / https 以外 (data: / blob:) と、**同じオリジン**は採らない。本文の中の
  添付画像を引いて動かすときもブラウザは `<img>` の URL を載せるので、拾うと
  移動のはずが絶対 URL の複製になる
- 画像の URL は**外部 URL のまま** `![](url)` で入れる。丸括弧は %28 / %29 にする
- 画像でないリンクは今までどおり文字で入る。本文の外に落としたときも、
  カーソルの位置に文字で入れる
- 対応外のファイルだけを落としたときは、知らせを出して何も入れない。
  CodeMirror 標準のドロップに回すと、ファイルを文字として読んで本文に入れてしまう

サーバに URL を渡して取り込む形は採らなかった。SSRF 対策・上限・中身の検査が
要るので、要るなら別の計画にする。外部 URL のままなので、元が消えれば表示も消える。

## 4. テスト

- 単体: `src/lib/editor/dropFiles.test.ts` (判定の境界)
- E2E: `e2e/drop.spec.ts`。合成の DragEvent で、本文の上・本文の外・画像の URL・
  普通のリンク (本文の上と外)・画像入りの文章の 6 通り。`/api/images` は route で横取りし、保存はしない
- **手で確かめること。** 合成イベントでは「受け損ねたらブラウザがファイルを
  開く」既定動作が起きない。Windows のエクスプローラから PNG を、本文の下の余白と
  下部バーのツールバーへ落とし、編集画面が残って画像が入ることを見る
