# 53. シークレット挿入拡張計画

[51-部分暗号化計画.md](./51-部分暗号化計画.md) の続き。シークレットの入力
ダイアログで扱えるのは markdown と画像だけだが、通常の編集画面で挿せるもの
(スキャン・録音・録画・お絵かき・OCR) はすべて入れられるようにする。

## 1. 種別ごとの成立性

隠したいものを隠せるか (= 平文がサーバへ出ないか) は道具ごとに違う。

| 道具 | 成立 | 理由 |
| --- | --- | --- |
| お絵かき | ○ | fabric は完全にブラウザ内。出力を画像と同じ経路で暗号化するだけ |
| 画像を OCR | ○ | 認識は Worker で完結 (docs/24)。復号済みの画素をそのまま食わせる |
| 録音 | ○ | 録音バイト列はブラウザ生成。暗号化して保存できる |
| 録画 | ○ | 同上。ただし上限とメモリの都合がある (§2) |
| スキャン | △ | **ここだけ性質が違う** (下記) |

**スキャンは「生コードの挿入」だけにする。** 読み取り後の書誌・商品情報の
取得は、コード (ISBN / JAN) を自サーバと外部 API へ送る。つまり「何を
スキャンしたか」がサーバ管理者に見える — シリアル番号のような隠したい
コードを入れる場面で、これは目的への裏切りになる。ダイアログでは
`prefillSummary` を**呼ばず**、読み取った文字をそのまま挿す。

## 2. 上限とメモリ

通常の添付は種別で上限が分かれている (動画 30MB / それ以外 10MB。
[uploads.ts](../src/lib/uploads.ts))。シークレットも同じ分け方にする —
サーバは中身を見られないので、判断材料は申告された mime だけになる。

再生には**ストリーミングが効かない**という制約がある。通常の音声・動画は
`/api/images` の Range 配信でシークできるが、シークレットは全体を復号して
から Blob URL で再生するため、ファイルぶんのメモリを掴む。数分の録音なら
実用上問題ないが、30MB の録画は端末によって重い。**上限は上げるが、長い
録画には向かない**ことを承知して使う。

## 3. mime の扱い

- 受け入れる mime に音声 (mp4 / webm) と動画 (mp4 / webm / quicktime) を足す。
- MediaRecorder が返す `audio/webm;codecs=opus` のようなパラメータ付きは、
  保存前に**基本形へ均す**。サーバは中身を見られないので、mime は許可リストと
  完全一致でなければ弾く方針を保つ。
- **AAD が mime を縛っている** (51 §7) ので、均す位置は暗号化の前でなければ
  ならない (均す前後で mime が変わると復号できなくなる)。

## 4. ダイアログのツール行

編集画面の下部バー (EditToolbar) は**流用しない**。あちらはページの下部バーへ
portal する作りで、全画面モーダルの下に潜る層にいる。「更新・元に戻す・
やり直す」も CodeMirror とフォームが前提で、textarea には意味がない。

流用するのは下の層 — アイコン ([MenuIcons.tsx](../src/components/MenuIcons.tsx))
とツールボタンの見た目。ダイアログの中に専用のツール行を持ち、見た目だけ
編集画面と揃える。

挿入先は textarea の選択範囲。純関数 `insertAtSelection()` に切り出して
テストする (CodeMirror の insertText に相当)。

## 5. 表示 (SecretBlock)

- 断片そのものが音声・動画のときは `<audio>` / `<video>` を Blob URL で描く。
- **断片の markdown に埋まった音声・動画**が問題になる。MarkdownView は
  URL の拡張子で音声・動画・PDF を描き分けているが、Blob URL には拡張子が
  無い。URL に細工をする (`#x.mp3` を足す) のは行儀が悪いので、
  **種別のマップを prop で渡す** — 描画に要る非同期の結果を呼び出し側が
  用意して渡すのは、`circuits` (回路図) と同じ既存の作法。

## 6. やらないこと

- スキャンからの書誌・商品情報の取得 (§1 のとおり)。
- PDF・テキストファイルの添付 (ファイル選択から入れるものは、暗号化して
  持つ意味が薄い。要求が出たら足す)。
- 断片内の音声・動画のシーク (Blob 再生なので全体を持つ。§2)。
