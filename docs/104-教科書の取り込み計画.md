# 教科書 (tommie-circuit-workbook) の取り込み計画

計画日: 2026-10-13 / 状態: **変換スクリプトと手元での取り込みの確認まで済 (§9)。本番・デモへは未着手。取り込んだ図が出るには [103](103-計器の画面と寸法図フェンス計画.md) の配布が要る**

教科書 6 冊 ([tommie-circuit-workbook](https://github.com/tommie-jp/tommie-circuit-workbook)、
本文 CC BY 4.0) の全題を、QR Note のノートとして読めるようにする。
測った数は 2026-10-13 時点の教科書の main。

## 1. 結論

- **取り込みは ZIP 取り込み (`/api/import`) に乗せる。** 専用の保存経路は作らない
  (`importZip.ts` の方針どおり)。教科書の Markdown を、QR Note の書き出し形式の ZIP に
  変換する**使い捨ての変換スクリプト**を書く
- **図は 103 の後でないと出ない。** 555 題のうち **472 題が新しい 6 つのフェンスを含む**。
  今の 3 種 (circuit・breadboard・perfboard) だけの題は 69 題、残りの 14 題は plantuml だけ (§3)
- **最初の取り込みは 1 冊だけ、本番ではなく手元かデモで。** 555 件を入れると、本番の
  832 件のメモの中で埋もれる (§5)
- 上限 (1 ノート 32,000 文字) を超える題が **5 件**ある。分けて入れる (§4)

## 4. 決め

| # | 決め | 理由 |
| --- | --- | --- |
| 1 | **front matter は外し、見出し行 (`# 1-8 …`) と、冊・章を示すタグを本文に足す** | 教科書の front matter は QR Note の書き出し形式のものと別。タグは `#tommie-circuit-workbook/06-fpga` の形で検索に使える |
| 2 | **フェンスが QR Note で描ける題は、下の画像の行 (Pages の SVG) を外す** | 同じ図が 2 つ出るため。描けない種類の題は画像の行を**残す** |
| 3 | **`plantuml` は処理系を足さず、画像の行を残す** | 81 題で、画像 (Pages の SVG) があればそれで足りる。**外部画像を QR Note が出せるかは未確認** (§6) |
| 4 | **32,000 文字を超える 5 題は、`##` の見出しで 2 つ以上に分ける** | 超える題 (文字数): `05-etc/02-radio-clock/05-clock.md` (64,298)・`05-etc/01-cpu/01-cpu-like.md` (54,308)・`01-circuits/09-rf/24-iq-mw-radio.md` (45,655)・`05-etc/02-radio-clock/04-state-machine.md` (44,724)・`06-fpga/06-state-machines/07-timer-99s.md` (35,866)。題名に `(1/2)` `(2/2)` を足す |
| 5 | **題どうしのリンク (`06-fpga/…md`) は、1 回目は文字のまま入れ、対応表ができてから貼り直す** | ノートの番号は取り込んでから決まる。変換スクリプトが `冊/id` → 番号の表を出す |
| 6 | **ノートの更新日・作成日は取り込んだ時刻のまま** | 教科書の git の日付を入れる意味が薄い |
| 7 | 取り込みの単位は **1 冊 1 ZIP**。冊ごとに確かめて、次へ進む | 失敗が冊に閉じる。教科書も冊ごとに順に書いてきた |

### 4-1. 変換スクリプトの置き場

`scripts/` に使い捨てで置く (`scripts/convertWorkbookToZip.mjs`)。**教科書は入れない** —
ノートの本文を ZIP にするだけで、出力は `_del/` に置く (コミットしない)。

## 5. どこへ入れるか — 決める必要がある

| 案 | 入れ先 | 利点 | 欠点 |
| --- | --- | --- | --- |
| A | **手元のローカル DB** (推奨の最初の 1 冊) | 本番に触れない。ZIP の取り込み・図・リンクを確かめられる | 自分しか見られない |
| B | **デモ (qr-demo)** | 他人にも見せられる。毎時リセットされるので壊れても戻る | リセットされるので、**種 (`qr_seed`) に入れないと定着しない** (`reseedDemo.sh`)。デモのノート数の上限 (`assertDemoItemQuota`) に当たる見込み |
| C | **本番に 555 件** | 一番簡単 | 832 件の個人のメモに 555 件が混ざる。**取り消すのも件数が多い** (ゴミ箱から消す) |

**推奨: A で 1 冊 (04-denken か 02-analog-discovery) → 問題がなければ B。C は最後に判断する。**
本番に入れるなら、タグ (決め 1) で絞れるのと、**ZIP の取り込みレポートに全件が出る**
(`importReport.ts`) のを使う。

## 6. 未確認・未決

- **外部画像の表示**: ノートに貼った `https://tommie-jp.github.io/…svg` を QR Note が
  表示するか (CSP・外部画像の扱い) を**確かめていない**。画像の行を残す題 (plantuml) は
  これが前提。出ない場合は、plantuml の図を画像として添付に取り込む
- **ZIP の front matter の扱い**: `noteFile.ts` の書き出し形式に、教科書の front matter の
  キーが邪魔にならないか。決め 1 のとおり外せばよいが、**往復の試験で確かめる**
- **公開範囲**: 取り込んだノートを公開 (`public_at`) にするかは決めない。既定は非公開
- **更新**: 教科書が更新されたときの再取り込みは扱わない (`isAlreadyImported` が重複を
  どう扱うかは取り込む前に確かめる)

## 7. 手順

1. 103 の第 1 段を実装して配布する
2. 変換スクリプトを書く。1 冊を ZIP にし、**手元の DB に入れて**図・リンク・タグを確かめる
3. 外部画像の表示を確かめる (§6)
4. 32,000 文字を超える 5 題の分け方を確かめる
5. デモ (または本番) に 1 冊を入れる。**入れる前に、あなたの確認を取る**
6. 残りの冊を順に

**本番への取り込みは、この計画書では実行しない。**

## 9. 手元での確認の結果 (2026-10-13)

`scripts/convertWorkbookToZip.mjs` で 6 冊を ZIP にし、試験用の DB (`qr_wb`。本物の写しの
`qr` とは別) に `scripts/importZipFile.ts` で取り込んだ。103 の第 1 段のブランチ
(`feat/instrument-fences`) の上で、dev サーバから公開ビューで見た。

| 冊 | 題 | ノート | 備考 |
| --- | --- | --- | --- |
| 01-circuits | 120 | 121 | `01-circuits/09-rf/24-iq-mw-radio.md` を 2 分割 |
| 02-analog-discovery | 100 | 100 | |
| 03-nanovna | 112 | 112 | 相対 SVG 3 を Pages の URL に |
| 04-denken | 100 | 100 | |
| 05-etc | 16 | 21 | 3 題を 2〜3 分割 |
| 06-fpga | 107 | 108 | 1 題を分割。相対 PNG 1 を添付に |
| **計** | **555** | **562** | **見送り 0** |

- **変換の中身 (§4 の決めどおり)**: front matter を外してタグ行を足す・描けるフェンスの下の
  Pages の画像行を外す (1,864 行。残した画像行は plantuml の 85 行)・`bread` `perf` を `breadboard` `perfboard` へ (65 か所)・
  題どうしのリンクを `/item/<itemNo>` へ (冊をまたぐリンクも)・32,000 文字超の 5 題を `##` で分割
- **itemNo は `wb<冊>-<章>-<題>`** (例 `wb04-06-01`)。番号を振らず、題の位置をそのまま名前にした。
  QR Note の itemNo は英数字・`-`・`_` の 20 字までの文字列なので入る。リンクの貼り直しが要らない
- 見送り 0・2 回目の取り込みは全件 `conflictSkipped` (冪等)・**画面で図が描かれる**
  (04-denken の 6-1 で、graph が 4 枚。タグ・題どうしのリンクも出る)
- **plantuml の画像 (外部の Pages SVG) は表示される**。06-fpga の 5-1 で naturalWidth 1360
- 教科書の `data:` は**どの題にも無かった** (測った値の重ね描きは使っていない)。103 の
  添付の口は教科書には要らないが、変換スクリプトは対応してある
- **まだ確かめていないこと**
  - **本番・デモへの取り込み**。ここまでは手元の試験 DB だけ
  - 本番の画面 (Caddy・実際の CSP) での外部画像の表示
  - 一覧・検索・タグ絞り込みの使い心地 (562 件が 832 件のメモに混ざったとき)
  - 分割した題 (`…a` `…b`) の見た目 (ナビの行)
  - 取り込み後の更新 (教科書の再取り込み。`overwrite` で置き換わる)
